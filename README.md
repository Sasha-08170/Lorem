# React + TypeScript + Vite

Типографика (body, font-family, color):

font-family: 'Inter', sans-serif; - Inter — популярный современный шрифт, который хорошо читается на темном фоне. (Вам нужно будет импортировать его, например, через Google Fonts).

color: #e0e0e0; - Слегка серый белый цвет для текста, чтобы он был менее резким на черном фоне, что улучшает комфорт чтения.

overflow-x: hidden; на body для предотвращения горизонтального скролла.

Пространство и размер (.card-container, .card-grid):

Увеличена max-width card-container до 1400px и padding для большего простора.

gap в card-grid увеличено до 40px для лучшего визуального разделения.

minmax(320px, 1fr) для grid-template-columns делает карточки чуть шире.

Интерактивность карточки (.card, .card:hover):

Более сложные переходы (transition): cubic-bezier функции для transform и box-shadow делают анимацию более естественной и "резиновой" при наведении.

Усиление эффекта подъема: transform: translateY(-12px) scale(1.02); при наведении делает карточку чуть больше и поднимает выше.

Более выраженная тень: Увеличены значения box-shadow в обычном состоянии и при наведении для придания большей глубины и "плавающего" эффекта.

background-color: #1a1a1a; - Чуть более светлый фон карточки для лучшего контраста с body и выделения на черном фоне.

Свечение (.card::before, .card:hover::before, @keyframes pulse):

inset: -1px; на ::before позволяет свечению чуть-чуть выходить за границы border-radius карточки, создавая эффект "дыхания" вокруг нее.

pointer-events: none; на ::before гарантирует, что этот декоративный псевдоэлемент не будет мешать взаимодействию с контентом.

transition: opacity 0.7s ease; - Более медленное и плавное появление свечения.

Увеличены значения opacity и box-shadow для radial-gradient и box-shadow на псевдоэлементах :nth-child для более сильного и выраженного неонового свечения.

Анимация pulse стала чуть менее агрессивной в transform: scale (1.04 вместо 1.05), чтобы не конкурировать с transform: scale(1.02) самой карточки, но opacity и box-shadow в ней усилены.

Ссылка и Заголовок (.card__link, .card__title):

display: flex; flex-direction: column; justify-content: flex-end; на card__link: Это мощное изменение. Оно позволяет автоматически прижимать заголовок (card__title) к низу карточки, создавая более современный и чистый вид, где "верх" карточки остается пустым для декорации.

padding: 35px 30px; - Немного увеличены отступы.

transition: color 0.3s ease; на card__link для плавного изменения цвета текста при наведении.

color: #f0f0f0; на card__link:hover для тонкой визуальной обратной связи.

font-size: 24px; font-weight: 700; line-height: 1.4; - Заголовок стал крупнее, жирнее и с лучшим межстрочным интервалом для читаемости.

margin-top: auto; на card__title работает с flex на .card__link, чтобы заголовок всегда прижимался к низу.

text-shadow: 0 2px 8px rgba(0, 0, 0, 0.4); - Небольшая тень для текста заголовка, которая улучшает его читаемость на фоне декорации.

Декорация (.card__decoration):

Увеличены height и width для более выраженного элемента.

Скорости transition настроены для гармоничного взаимодействия с анимацией карточки.

opacity: 0.7; и filter: blur(2px); в обычном состоянии, чтобы она была более мягкой.

transform: scale(8.5); opacity: 0.45; filter: blur(4px); при наведении для более сильного эффекта "растворения" и расширения.

Адаптивность (@media):

Добавлен дополнительный брейкпойнт для 1200px для более плавного перехода.

Небольшие корректировки gap, padding и font-size на разных брейкпойнтах для оптимального отображения.

На мобильных устройствах (480px) min-height: auto; для заголовка, чтобы он мог адаптироваться к любой длине текста.
